# Block Me Build Me

Falling-block puzzle for phones. Stack tetrominoes, clear lines, chase the board.

A self-contained HTML5 canvas game. No build step.

## How to play

**Touch:** swipe left/right to move, swipe down for a soft drop, tap or swipe up to rotate. Use the drop control for a hard drop.

**Keyboard:** arrows move, Up or X rotate, Down soft drop, Space hard drop.

**Keys:** `M` mute · `P` or `Esc` pause · Enter starts

A 10-slot high-score board lives on the device. Qualifying runs also register on the **Seeker fleet** when this game is opened from Ionwake.

## Seeker / mobile

Portrait 9:16, 44px tap targets, safe-area padding. Built for Seeker mobile shells.

## Open

Open `index.html` in a browser, or play it from the Ionwake fleet arcade.
